# Sanaullah Khan | Portfolio

My personal portfolio website, built as a flip-able student ID card followed by my skills, projects and roadmap.

**Live site:** https://sanaullahkhan9838.github.io/portfolio/

## Features

- Student ID card hero that flips to show contact details and a QR code
- Fully responsive: phone, tablet, laptop, and phone rotation (portrait and landscape)
- Skills, projects with live demo links, software engineering roadmap and contact links
- All content lives in one file (`data.js`), so updating it never touches the layout code

## Tech

HTML, CSS and vanilla JavaScript. No build step and no framework. Hosted on GitHub Pages.

## Project structure

| File | Purpose |
|---|---|
| `index.html` | Page layout, styles and rendering code |
| `data.js` | All my personal data: name, bio, links, skills, projects |
| `photo.jpg` | Profile photo shown on the ID card |

## How to update the content

1. Open `data.js` in this repo and click the pencil icon.
2. Change the text inside the quotes (`"..."`). Keep the commas.
3. To add a project, copy one `{ ... }` block inside `projects` and edit it.
4. Commit the change. The site updates in 1 to 2 minutes.
